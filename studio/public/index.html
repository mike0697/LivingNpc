How to write

      
Every file is made of quest blocks (the mission and its stages) and event blocks (the messages: what happens and what is said). Every line is one of these:

      
    
        
  • property: title = "The chest", trigger = talk, npc = elena
    • 
        
  • dialogue line: elena: "Hello!" · with a pose elena [happy]: "How nice!" · without a name say("You hear a noise.")
    • 
        
  • command: giveItem(gold_coin, 100), show(chest, "chest.png", x=40, y=30)
    • 
        
  • block: ends with : and holds the lines indented by 4 spaces below it
    • 
      

      
The commands of a message run in order, from top to bottom. Useful blocks:


event ev_chest:
    trigger = enterNode        # when it starts: enterNode, talk, tick, wake
    node = bedroom
    once = true                # only once
    when:                      # start conditions (all true)
        quest(q_chest, active)

    say("There is an old chest.")
    show(chest, "chest.png", x=40, y=30)
    choice:
        option "Open it":
            hide(chest)
            giveItem(gold_coin, 100)
            completeQuest(q_chest)
        option "Leave it" if flag(scared):
            pass               # nothing to do
    if hasItem(key):
        say("The key fits the lock.")
    else:
        say("You need a key.")

      
A quest has stages (stage) with the journal text and the complete: / fail: conditions; the onStart:, onComplete:, onFail: blocks accept only game commands (no dialogue lines: those go in a message).

      
Automatic quests

      
A template is a quest the characters pick and do by themselves (those with “Automatic quests” on in the Characters tab). When a character is free it looks at the templates it can do (when:), fills the slots (another character, a place, an item) and picks one at random, weighted by its weight:. Conditions and commands use self (the character) and the slot names; the texts say {self}, {friend}, {friend.first}, {friend:him|her}.


template t_bread:
    title = "{self} brings bread to {friend}"
    pauseDays = 1                  # days before the next one
    when:                          # who can pick it
        hasItem(bread, target=self)
    weight:                        # how much it wants it
        base = 10
        goals = {"help": 30}
    slot friend:
        type = npc                 # npc, place (of = …, place = home), node, item
        when:
            relation(self, it, ">=", 10)
    slot house:
        type = place
        of = friend
        place = home
    texts:
        intro:
            variant if stat(happiness, ">=", 60, target=self):
                "Off to {friend}, with fresh bread!"
            variant:
                "I should bring {friend} some bread."
        talk:                      # when the player talks to them meanwhile
            "Sorry, I am bringing bread to {friend}."
    stage go:
        onStart:
            tell(intro)            # a line in the log, if the player is there
            moveNpc(self, house, forMinutes=180)
        complete:
            npcAt(self, house)
    stage give:
        complete:
            elapsed(minutes=30)
            chance(80)             # fixed when the stage begins
        onComplete:
            takeItem(bread, target=self)
            giveItem(bread, target=friend)
            modRelation(friend, self, 10)

      
Lines shared by every template go in lines greet: blocks (the files of lines/), said with tell(greet).

      
# starts a comment (it is not saved). The text is saved in the game's JSON files: Save (Ctrl+S) writes them, and the “JSON to be saved” panel shows them first.

      
The other tabs

      
    
        
  • Characters: the characters (NPCs) with first name, last name, age, sex, goal, relations and automatic quests on / off, their places, their weekly routine (with a chart of where they are at every hour), stats, inventory and images; and the routines shared by several characters.
    • 
        
  • Items: name, description, type and value of every item.
    • 
        
  • Rules: start time and day, starting inventory, stats, activities, dayparts, sleep, goals and the automatic quests (rules.json).
    • 
        
  • System: the game title, the main menu of the game (background image, title, music) and the images of the game and menu buttons, with a preview (title.json).
    • 
      

      
Every tab has a Form and the JSON view with the file as it is. On the right you find the problems, where it is used and the JSON to be saved.
